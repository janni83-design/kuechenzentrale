# Küchenzentrale

Familien-App für Speiseplan, Einkaufsliste, Angebote, Budget und Rezepte.
Eine einzelne statische Seite (`index.html` + `fotos/`), veröffentlicht über GitHub Pages.

Auf dem Handy im Browser öffnen und „Zum Home-Bildschirm“ wählen.
Abhaken, Bewertungen und Tauschwünsche werden lokal im Browser des jeweiligen Geräts gespeichert.
